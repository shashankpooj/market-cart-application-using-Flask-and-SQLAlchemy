# market-cart-application-using-Flask-and-SQLAlchemy

A secure and user-friendly e-commerce web application built with **Flask**. This project lets users register, log in, browse items, purchase them, and view session based transaction history—all with a clean Bootstrap UI and **XAMPP MySQL** as the backend database.

---

## ✅ Key Features

- 🔐 **User Authentication** using Flask-Login  
- 🛍️ **Dynamic Item Listing** with purchasing capability  
- 🧾 **Session-Based Purchase Tracking** (No database logging)  
- ⚡ **Real-time Flash Messages** for user feedback  
- 🎨 **Responsive UI** using Bootstrap  
- 📜 **Modular Templates** with Jinja2  
- 📊 **View Session Purchase History** per user session  
- 🗃️ **XAMPP MySQL Integration** for storing users and items  

---

## 🛠️ Technologies Used

- Python, Flask  
- Jinja2 Templates  
- Bootstrap (Responsive Frontend)  
- Flask-Login, Flask-WTF  
- XAMPP MySQL (MariaDB)
